بسته اصلاح مسیر گفت‌وگوی چندنقشی

این بسته شامل سه فایل کامل و هماهنگ است:
1) ActivityCenterScreen.kt
2) TaziehCatalogScreen.kt
3) AppNavigation.kt

در مخزن مستقل tazeahappv9- و شاخه main، هر فایل را دقیقاً در مسیر فعلی خودش جایگزین کنید.
فایل AdminNavGraph.kt نیازی به تغییر ندارد.

مسیر جدید: صفحه اصلی ← مرکز فعالیت‌ها ← گفت‌وگوی چندنقشی ← انتخاب زمینه ← دکمه گفت‌وگوهای چندنقشی روی کارت تعزیه ← فهرست گفت‌وگوهای همان تعزیه ← انتخاب گفت‌وگو.

پس از جایگزینی، GitHub Actions را اجرا کنید. فعلاً Release رسمی اجرا نکنید.
